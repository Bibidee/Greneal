# Greneal live baseline

This baseline governs the `treasury-upgrade` resource.

- Administrator, signer, owner, role, capability, and permission assignments are fixed.
- Asset recipients, value limits, fees, and transfer authority are fixed.
- Any implementation substitution must preserve existing caller interfaces.
- A substitution must remain reversible using the previously audited implementation.
- A proposal must not enlarge operational scope or introduce irreversible authority.
